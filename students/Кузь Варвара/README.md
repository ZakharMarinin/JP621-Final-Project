# Терравариум

Консольная утилита для содержания виртуальных питомцев.
Каждый питомец имеет голод, энергию, здоровье и настроение,
которые меняются со временем и от действий владельца.
Данные хранятся в JSON между запусками.

## Требования

- Python 3.10+
- Сторонних библиотек не требуется

## Запуск

Все команды выполняются из корня проекта:

```bash
python main.py <команда> [аргументы]
